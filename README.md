# COS 201 - Computer Programming I (Week 3)

## Programs
- **SimpleCalculator.java**: performs +, -, *, / on two numbers.
- **AverageCalculator.java**: reads a set of numbers and prints their sum and average.
- **ItemCost.java**: calculates the total cost of an item from unit price and quantity.

## Requirements
- Java Development Kit (JDK) 8 or later

## How to compile
```
javac SimpleCalculator.java
javac AverageCalculator.java
javac ItemCost.java
```

## How to run
```
java SimpleCalculator
java AverageCalculator
java ItemCost
```
Each program prompts you for input in the terminal.

## Sample run (SimpleCalculator)
```
Enter first number: 8
Enter an operator (+, -, *, /): *
Enter second number: 5
Result: 40.0
```
